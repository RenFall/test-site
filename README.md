# paper.site 

Это экспериментальный автономный сайт на термобумаге 57×25 мм. QR содержит полный HTML, CSS, JavaScript и тексты анекдотов. Никакой сервер и доступ в интернет для чтения содержимого не нужны. Читателю требуется универсальный локальный считыватель `index.html` — обычные QR-сканеры могут не открывать `data:`-адрес.


## Как использовать

1. Распечатать подходящую этикетку PNG/PDF **в масштабе 100%**, без сглаживания.
2. Открыть заранее сохранённый на устройстве `paper_reader.html` (первоначальная установка не требует сервера: перенос файла по кабелю тоже подходит).
3. Нажать «Сфотографировать этикетку», выбрать фото или попробовать камеру. При необходимости — скопировать текст QR из другого сканера и вставить вручную.
4. После проверки хеша показывается paper.site в изолированном iframe. «Ещё шутку» переключает анекдоты без повторов до конца цикла.

**Внимание:** `file://`-страницы в отдельных мобильных браузерах не имеют доступа к камере или `crypto.subtle`. Если проверка SHA-256 недоступна, считыватель безопасно откажет в запуске; здесь потребуется другой локальный способ запуска с разрешёнными веб-API. Реальная печать и сканирование Google Lens не тестировались. Выцветание и точность печати зависят от бумаги и принтера.
